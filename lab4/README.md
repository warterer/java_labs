# Лабораторна робота №4: generics

**Завдання 4.1: Транспортні засоби та пасажири**

Ієрархія транспортних засобів, які перевозять різні типи пасажирів. Обмеження на тип
пасажира (пожежна машина тільки для пожежників, поліцейська тільки для поліцейських)
задаються за допомогою generics і перевіряються компілятором.

## Ієрархії

```
Людина (Human)                    Транспортний засіб (Vehicle<T extends Human>)
├── Пожежник (Firefighter)        ├── Автобус (Bus)            Vehicle<Human>
└── Поліцейський (Policeman)      └── Автомобіль (Car<T>)
                                      ├── Таксі (Taxi)               Car<Human>
                                      ├── Поліцейська машина         Car<Policeman>
                                      └── Пожежна машина             Car<Firefighter>
```

| Транспортний засіб | Кого перевозить | Місць за замовчуванням |
|---|---|---|
| `Bus` | будь-яких людей | 30 |
| `Taxi` | будь-яких людей | 4 |
| `PoliceCar` | тільки поліцейських | 4 |
| `FireTruck` | тільки пожежників | 6 |

Кількість місць задається в конструкторі (`new Taxi(2)`).

## Як працюють generics

- `Vehicle<T extends Human>` це обмежений параметр типу: `T` може бути `Human` або його підкласом. Метод `board(T passenger)` приймає тільки такий тип.
- `FireTruck extends Car<Firefighter>`: посадити в неї поліцейського не можна (`Policeman cannot be converted to Firefighter`).
- `Bus` і `Taxi` оголошені як `Vehicle<Human>` / `Car<Human>`, тому приймають будь-кого, у тому числі пожежників і поліцейських.
- **Інваріантність:** `FireTruck` це `Vehicle<Firefighter>`, але не `Vehicle<Human>`, хоч `Firefighter` є `Human`. Тому для списку машин на дорозі використовується wildcard.
- `Road` зберігає `List<Vehicle<? extends Human>>` і приймає `Vehicle<? extends Human>`. Такий запис підходить для машини з будь-яким типом пасажирів. Через нього пасажирів можна лише читати, а не додавати, що для підрахунку людей і потрібно.

## Функції транспортних засобів

| Метод | Опис |
|---|---|
| `getMaxSeats()` | максимальна кількість місць |
| `getOccupiedSeats()` | кількість зайнятих місць |
| `board(T)` | посадка; якщо місць немає, кидає `VehicleFullException` |
| `disembark(T)` | висадка; якщо пасажира немає, кидає `PassengerNotFoundException` |
| `getPassengers()` | пасажири (список тільки для читання) |

Клас `Road`:
- `addCarToRoad(Vehicle<? extends Human>)` додає транспортний засіб на дорогу;
- `getCountOfHumans()` підраховує кількість людей у всіх транспортних засобах на дорозі.

## Тести

Усього 18 тестів:

- **`VehicleTest`**: таксі й автобус приймають будь-яких пасажирів; пожежна машина приймає пожежників, поліцейська поліцейських; максимальна та зайнята кількість місць; посадка в повний транспорт кидає виняток; висадка звільняє місце й видаляє саме вказаного пасажира; висадка відсутнього (або вдруге) кидає виняток; повторна посадка тієї самої людини; некоректна кількість місць; список пасажирів тільки для читання.
- **`RoadTest`**: порожня дорога; підрахунок людей у машинах з різними типами пасажирів; зміна підрахунку при посадці та висадці; заборона додати одну машину двічі; заборона `null`.
