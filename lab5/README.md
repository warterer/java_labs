# Лабораторна робота 5. I/O Streams

## Завдання

1. **Рядок з максимальною кількістю слів.** Програма читає файл `input.txt` і виводить рядок, у якому найбільше слів.
2. **Шифрування та дешифрування.** Код кожного символу збільшується на код ключового символу (шифрування) або зменшується на нього (дешифрування). Реалізовано через потоки `FilterWriter` і `FilterReader`.
3. **Частота тегів на сторінці за URL.** Результат виводиться двома способами: у лексикографічному порядку та за зростанням частоти появи тегів.

## Структура проєкту

| Файл | Призначення |
|------|-------------|
| `Main.java` | Меню, налаштування файлів, ключа та URL, обробка помилок |
| `FileService.java` | Уся робота з файлами та потоками в окремому класі |
| `CaesarWriter.java` | `FilterWriter`, який шифрує символи при записі |
| `CaesarReader.java` | `FilterReader`, який дешифрує символи при читанні |
| `TagCounter.java` | Підрахунок тегів і виведення результатів |
| `input.txt` | Вхідний файл для тестування |

## Налаштування

Файли, ключ і URL задаються константами на початку `Main.java`:

```java
private static final String inputFile = "input.txt";
private static final String encryptedFile = "encrypted.txt";
private static final String decryptedFile = "decrypted.txt";
private static final char key = 'k';
private static final String url = "https://github.com/";
```

## Як запустити

- **Демо:** `src/main/java/lab5/Main.java`

## Меню

```
1. Рядок з максимальною кількістю слів у input.txt
2. Зашифрувати input.txt в encrypted.txt
3. Розшифрувати encrypted.txt в decrypted.txt
4. Частота тегів на заданому URL
0. Вихід
```

## Обробка помилок

Усі операції виконуються всередині блоків `try-catch`. Якщо файл не знайдено, URL недоступний або сталася інша помилка, програма виводить повідомлення «Помилка: ...» і повертається до меню.
