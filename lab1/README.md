# Лабораторна робота №1: Робота з рядками та масивами в Java

## Варіант 3
Знайти слова, які містять тільки символи латинського алфавіту, та серед них відібрати ті, що мають однакову кількість голосних і приголосних літер.

## Реалізація
- **`WordFilter`**:
    - `findBalancedLatinWords(String text)` — розбиває вхідний рядок за пробільними символами та фільтрує слова.
    - `isLatinOnly(String word)` — перевіряє, що слово складається суто з латинських літер (`a-z`, `A-Z`).
    - `hasEqual(String word)` — підраховує кількість голосних і приголосних літер та перевіряє їх рівність.
- **`Main`**: точка входу з набором тестових даних для демонстрації роботи програми.

## Запуск
```bash
javac src/WordFilter.java src/Main.java
java -cp src Main
